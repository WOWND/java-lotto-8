# java-lotto-precourse
## 구현 기능 목록

---
### 입력
- [x] 로또 구입 금액
  - [x] 1000원 단위
  - [x] 최소 1000원
- [x] 당첨 번호
  - [x] 6개
  - [x] 1~45 사이의 번호
  - [x] 중복 불가
- [x] 보너스 번호
  - [x] 당첨 번호와 중복 불가


### 로또
- [x] 구입 금액 만큼 로또 발행
    - [x] 로또 번호 추출
- [ ] 당첨 등수 계산
    - [ ] 당첨 금액 합산
    - [ ] 당첨 내역 관리
- [ ] 수익률 계산

### 출력
- [x] 발행한 로또 수량
- [x] 수량만큼의 로또 번호 오름차순
- [ ] 당첨 내역
- [ ] 수익률 소수점 둘쨰 자리에서 반올림
- [ ] 예외 상황 시 에러 문구 출력
