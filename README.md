# java-lotto-precourse

## 개요
로또 게임의 당첨 결과를 분석하고 수익률을 평가하는 프로그램입니다.
사용자는 구입 금액, 당첨 번호, 보너스 번호를 입력하여
당첨 통계와 수익률을 확인할 수 있습니다.

## 기능 요구 사항
- 로또 번호의 숫자 범위는 1~45까지이다.
- 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
- 당첨 번호 추첨 시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.
- 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.
  - 1등: 6개 번호 일치 / 2,000,000,000원
  - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
  - 3등: 5개 번호 일치 / 1,500,000원 
  - 4등: 4개 번호 일치 / 50,000원
  - 5등: 3개 번호 일치 / 5,000원
- 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다.
- 로또 1장의 가격은 1,000원이다.
- 당첨 번호와 보너스 번호를 입력받는다.
- 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다.
- 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
  - Exception이 아닌 IllegalArgumentException, IllegalStateException 등과 같은 명확한 유형을 처리한다.

## 입출력 요구 사항
### 입력
- 로또 구입 금액을 입력 받는다. 구입 금액은 1,000원 단위로 입력 받으며 1,000원으로 나누어 떨어지지 않는 경우 예외 처리한다.
```aiexclude
14000
```
- 당첨 번호를 입력 받는다. 번호는 쉼표(,)를 기준으로 구분한다.
```aiexclude
1,2,3,4,5,6
```
- 보너스 번호를 입력 받는다.
```aiexclude
7
```

### 출력
- 발행한 로또 수량 및 번호를 출력한다. 로또 번호는 오름차순으로 정렬하여 보여준다.
```aiexclude
8개를 구매했습니다.
[8, 21, 23, 41, 42, 43]
[3, 5, 11, 16, 32, 38]
[7, 11, 16, 35, 36, 44]
[1, 8, 11, 31, 41, 42]
[13, 14, 16, 38, 42, 45]
[7, 11, 30, 40, 42, 43]
[2, 13, 22, 32, 38, 45]
[1, 3, 5, 14, 22, 45]
```
- 당첨 내역을 출력한다.
```aiexclude
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
```
- 수익률은 소수점 둘째 자리에서 반올림한다. (ex. 100.0%, 51.5%, 1,000,000.0%)
```aiexclude
총 수익률은 62.5%입니다.
```
- 예외 상황 시 에러 문구를 출력해야 한다. 단, 에러 문구는 "[ERROR]"로 시작해야 한다.
```aiexclude
[ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
```

## 구현 기능 목록


### 입력
- [x] 로또 구입 금액
- [x] 당첨 번호
- [x] 보너스 번호
- [x] 예외 발생 시 메시지 출력 후 재시도


### 로또
- [x] 구입 금액 만큼 로또 발행
    - [x] 로또 번호 추출
- [x] 당첨 등수 계산
    - [x] 당첨 금액 합산
    - [x] 당첨 내역 관리
- [x] 수익률 계산

### 출력
- [x] 발행한 로또 수량
- [x] 수량만큼의 로또 번호 오름차순
- [x] 당첨 내역
- [x] 수익률 소수점 둘째 자리에서 반올림

---

### 예외 상황

로또 구입
- [x] 구입 금액이 1,000원 단위가 아닌 경우
- [x] 1,000원 미만으로 구입한 경우

당첨 번호
- [x] 당첨 번호가 6개가 아닌 경우
- [x] 당첨 번호가 유효하지 않은 범위인 경우
- [x] 중복된 번호를 입력한 경우

보너스 번호
- [x] 당첨 번호와 중복되는 경우
- [x] 보너스 번호가 유효하지 않은 범위인 경우
- [x] 당첨 번호 입력 전에 보너스 번호를 먼저 입력하는 경우

로또 번호
- [x] 로또 번호에 중복된 숫자가 있는 경우
- [x] 로또 번호가 6개가 아닌 경우


## 계층 구조

Model-View-Controller 패턴을 사용하여
사용자 입력(View) → 비즈니스 로직 처리(Model) → 결과 출력(View)의 
책임을 분리하여 코드의 유지보수성과 확장성을 높였습니다.

```aiexclude
lotto/
├── controller/
│   └── LottoController
├── model/
│   ├── domain/
│   │   ├── Lotto                   # 로또 도메인 모델
│   │   ├── LottoConstants          # 로또 상수 (개수, 최댓값 등)
│   │   └── LottoRank               # 당첨 등급
│   ├── dto/
│   │   └── LottoResultDto          # 당첨 결과 데이터
│   └── service/
│       └── LottoService            # 로또 비즈니스 로직
├── util/               
│   ├── parser/
│   │   ├── NumberParser            # 숫자 파싱
│   │   └── WinningNumberParser     # 당첨 번호 파싱
│   └── validator/
│       ├── InputValidator          # 입력값 공통 검증
│       ├── LottoNumbersValidator   # 로또 번호 검증
│       └── PurchaseAmountValidator # 구 금액 검증
├── view/               
│   ├── InputView                   # 사용자 입력 처리
│   ├── OutputView                  # 결과 출력 처리
│   └── ViewMessages                # 출력 메시지 상수
│
└── Application                     # 프로그램 엔트리 포인트
```
